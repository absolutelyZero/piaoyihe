# GUI调整计划

## 问题列表

### 1. 左右比例不协调
**现状**：从截图看，左侧功能区和右侧预览区比例可能不够协调
**期望**：调整左右分割器比例，使布局更协调

**修复方案**：
- 修改 `_init_ui` 中的分割器比例设置
- 调整左:右比例，需要改为 6:4

### 2. 配置项和操作面板样式不协调，需要更紧凑
**现状**：布局选择、处理模式、排序方式等配置项与操作按钮区域样式不够协调，间距过大
**期望**：
- 统一卡片样式
- 减少内边距和间距，使布局更紧凑
- 调整控件大小和对齐方式

**修复方案**：
- 修改 `_create_options_widget` 方法
- 减少布局间距（spacing）和内边距（contentsMargins）
- 调整单选按钮和下拉框的大小

### 3. 版本号位置调整
**现状**：版本号在底部区域
**期望**：将版本号移到右上角，问题反馈按钮的左侧

**修复方案**：
- 从 `_create_bottom_widget` 中移除版本号
- 在 `_create_top_widget` 中添加版本号标签
- 将版本号放在反馈按钮左侧

### 4. 问题反馈弹窗增加二维码
**现状**：反馈弹窗只有使用帮助内容
**期望**：在弹窗最底部增加"有其他问题可以扫码反馈"文字和二维码图片

**修复方案**：
- 修改 `FeedbackDialog` 类
- 在底部添加 QLabel 显示提示文字
- 添加 QLabel 显示二维码图片（`d:\minipro\piaoyihe\piaoyihe\code\res\qrcode.jpg`）
