# 发票字段提取重构方案

## 一、当前问题分析

### 1.1 代码现状
当前 `pdf_handler.py` 中的字段提取逻辑采用**集中式大方法**设计：

```python
class PDFHandler:
    def extract_amount(self, pdf_path): ...        # 300+ 行
    def extract_invoice_date(self, pdf_path): ...  # 100+ 行  
    def extract_invoice_type(self, pdf_path): ...  # 80+ 行
    def extract_product_type(self, pdf_path): ...  # 60+ 行
    def extract_buyer_name(self, pdf_path): ...    # 60+ 行
    def extract_seller_name(self, pdf_path): ...   # 60+ 行
```

**核心问题：**
- 每个字段提取方法内包含**多种票种的混合逻辑**（普票、专票、火车票、飞机票等）
- 修改A票种的识别规则时，容易**意外影响B票种**
- 代码可读性差，难以维护
- 新增票种需要修改多处代码

### 1.2 票种类型梳理
根据现有代码，识别的票种包括：
1. **增值税普通发票**（普票）
2. **增值税专用发票**（专票）
3. **机动车发票**
4. **火车票/铁路电子客票**
5. **飞机票/航空电子客票**
6. **出租车发票**
7. **定额发票**
8. **通行费/ETC发票**

### 1.3 需要提取的字段
- `amount` - 金额
- `invoice_date` - 开票日期
- `invoice_type` - 发票类型
- `product_type` - 商品类型
- `buyer_name` - 购买方名称
- `seller_name` - 销售方名称

---

## 二、重构方案：策略模式 + 工厂模式

### 2.1 设计思路

采用**策略模式（Strategy Pattern）** + **工厂模式（Factory Pattern）**进行重构：

```
┌─────────────────────────────────────────────────────────────┐
│                    InvoiceExtractor (抽象基类)                │
│  ┌─────────────┐  ┌─────────────┐  ┌─────────────────────┐  │
│  │ extract_    │  │ extract_    │  │ extract_            │  │
│  │ amount()    │  │ date()      │  │ type()              │  │
│  └─────────────┘  └─────────────┘  └─────────────────────┘  │
└─────────────────────────────────────────────────────────────┘
                              ▲
                              │ 继承
        ┌─────────────────────┼─────────────────────┐
        │                     │                     │
┌───────▼──────┐    ┌────────▼────────┐   ┌───────▼────────┐
│ 普通发票     │    │ 火车票提取器    │   │ 飞机票提取器   │
│ 提取器       │    │                 │   │                │
│              │    │ extract_xxx()   │   │ extract_xxx()  │
│ 实现各字段   │    │ 实现各字段      │   │ 实现各字段     │
│ 提取逻辑     │    │ 提取逻辑        │   │ 提取逻辑       │
└──────────────┘    └─────────────────┘   └────────────────┘
```

### 2.2 核心优势

1. **隔离性**：每种票种的提取逻辑完全独立，修改A票种不会影响B票种
2. **可扩展性**：新增票种只需添加新的提取器类，无需修改现有代码（开闭原则）
3. **可测试性**：每种票种的提取器可以独立单元测试
4. **可读性**：每个类的职责单一，代码结构清晰

### 3.2 核心类设计

#### 3.2.1 抽象基类 (base.py)

```python
from abc import ABC, abstractmethod
from typing import Dict, Any
import fitz


class InvoiceExtractor(ABC):
    """
    发票字段提取器抽象基类
    
    所有具体票种提取器必须继承此类，实现各字段的提取方法
    """
    
    # 票种标识符，用于工厂匹配
    INVOICE_TYPE_KEYWORDS: list = []
    
    def __init__(self, pdf_path: str):
        self.pdf_path = pdf_path
        self._doc = None
        self._text = None
        self._pages = []
    
    def __enter__(self):
        """上下文管理器入口"""
        self._doc = fitz.open(self.pdf_path)
        self._pages = [self._doc[i] for i in range(len(self._doc))]
        self._text = "\n".join([page.get_text() for page in self._pages])
        return self
    
    def __exit__(self, exc_type, exc_val, exc_tb):
        """上下文管理器出口"""
        if self._doc:
            self._doc.close()
        return False
    
    @classmethod
    def can_handle(cls, text: str) -> bool:
        """
        判断是否能处理该文本内容
        
        Args:
            text: PDF文本内容
            
        Returns:
            bool: 是否能处理
        """
        return any(keyword in text for keyword in cls.INVOICE_TYPE_KEYWORDS)
    
    @abstractmethod
    def extract_amount(self) -> float:
        """提取金额"""
        pass
    
    @abstractmethod
    def extract_invoice_date(self) -> str:
        """提取开票日期"""
        pass
    
    @abstractmethod
    def extract_invoice_type(self) -> str:
        """提取发票类型"""
        pass
    
    @abstractmethod
    def extract_product_type(self) -> str:
        """提取商品类型"""
        pass
    
    @abstractmethod
    def extract_buyer_name(self) -> str:
        """提取购买方名称"""
        pass
    
    @abstractmethod
    def extract_seller_name(self) -> str:
        """提取销售方名称"""
        pass
    
    def extract_all(self) -> Dict[str, Any]:
        """
        一次性提取所有字段
        
        Returns:
            Dict[str, Any]: 包含所有字段的字典
        """
        return {
            'amount': self.extract_amount(),
            'invoice_date': self.extract_invoice_date(),
            'invoice_type': self.extract_invoice_type(),
            'product_type': self.extract_product_type(),
            'buyer_name': self.extract_buyer_name(),
            'seller_name': self.extract_seller_name(),
        }
```

#### 3.2.2 工厂类 (factory.py)

```python
from typing import Type, Optional
import fitz
from .base import InvoiceExtractor

# 导入所有具体提取器
from .common_invoice import CommonInvoiceExtractor
from .train_ticket import TrainTicketExtractor
from .flight_ticket import FlightTicketExtractor
from .vehicle_invoice import VehicleInvoiceExtractor
from .taxi_invoice import TaxiInvoiceExtractor
from .fixed_amount_invoice import FixedAmountInvoiceExtractor
from .toll_invoice import TollInvoiceExtractor


class InvoiceExtractorFactory:
    """
    发票提取器工厂类
    
    根据PDF内容自动选择合适的提取器
    """
    
    # 注册所有提取器，按优先级排序
    _extractors: list[Type[InvoiceExtractor]] = [
        TrainTicketExtractor,      # 火车票 - 优先级高（特征明显）
        FlightTicketExtractor,     # 飞机票 - 优先级高（特征明显）
        VehicleInvoiceExtractor,   # 机动车发票
        TaxiInvoiceExtractor,      # 出租车发票
        FixedAmountInvoiceExtractor,  # 定额发票
        TollInvoiceExtractor,      # 通行费发票
        CommonInvoiceExtractor,    # 普通发票 - 兜底
    ]
    
    @classmethod
    def get_extractor(cls, pdf_path: str) -> Optional[InvoiceExtractor]:
        """
        根据PDF路径获取合适的提取器
        
        Args:
            pdf_path: PDF文件路径
            
        Returns:
            Optional[InvoiceExtractor]: 提取器实例，或None
        """
        try:
            with fitz.open(pdf_path) as doc:
                text = "\n".join([page.get_text() for page in doc])
                
                for extractor_class in cls._extractors:
                    if extractor_class.can_handle(text):
                        return extractor_class(pdf_path)
                        
        except Exception as e:
            print(f"获取提取器失败: {str(e)}")
            
        return None
    
    @classmethod
    def register_extractor(cls, extractor_class: Type[InvoiceExtractor], priority: int = -1):
        """
        注册新的提取器
        
        Args:
            extractor_class: 提取器类
            priority: 优先级，越小越优先，-1表示添加到末尾
        """
        if priority >= 0:
            cls._extractors.insert(priority, extractor_class)
        else:
            cls._extractors.append(extractor_class)
```

#### 3.2.3 普通发票提取器 (common_invoice.py)

```python
import re
from typing import List, Tuple
import fitz
from .base import InvoiceExtractor


class CommonInvoiceExtractor(InvoiceExtractor):
    """
    普通发票提取器（增值税普通/专用发票）
    
    作为兜底提取器，处理常规增值税发票
    """
    
    INVOICE_TYPE_KEYWORDS = ["发票"]  # 兜底匹配
    
    def extract_amount(self) -> float:
        """
        提取金额
        
        策略：
        1. 优先查找"价税合计"附近的金额
        2. 查找"合计金额"字段
        3. 查找最大的金额数字
        """
        amount_max = 0.0
        
        for page in self._pages:
            blocks = page.get_text("blocks")
            
            # 策略1：查找关键词附近的金额
            amount_keywords = ["价税合计", "合计", "金额", "¥", "￥", "小写"]
            
            for block in blocks:
                x0, y0, x1, y1, text, block_no, block_type = block
                text_clean = text.replace(' ', '').strip()
                
                for keyword in amount_keywords:
                    if keyword in text_clean:
                        pattern = r'[¥￥]?\s*(\d+(?:,\d{3})*(?:[.·]\d+)?)'
                        match = re.search(pattern, text_clean)
                        if match:
                            amount_str = match.group(1).replace(',', '').replace('·', '.')
                            try:
                                amount = float(amount_str)
                                if amount > amount_max:
                                    amount_max = amount
                            except ValueError:
                                pass
            
            # 策略2：全局查找金额格式
            if amount_max == 0:
                patterns = [
                    r'¥\s*(\d+(?:,\d{3})*(?:[.·]\d+)?)',
                    r'￥\s*(\d+(?:,\d{3})*(?:[.·]\d+)?)',
                    r'(\d+(?:,\d{3})*(?:[.·]\d+)?)\s*元',
                ]
                
                for pattern in patterns:
                    matches = re.findall(pattern, self._text)
                    for match in matches:
                        try:
                            amount_str = match.replace(',', '').replace('·', '.')
                            amount = float(amount_str)
                            if amount > amount_max:
                                amount_max = amount
                        except ValueError:
                            pass
        
        return amount_max
    
    def extract_invoice_date(self) -> str:
        """
        提取开票日期
        
        策略：
        1. 优先匹配"开票日期:"后面的日期
        2. 匹配其他日期格式
        3. 返回文件修改日期作为备选
        """
        # 策略1：优先匹配"开票日期:"
        invoice_date_pattern = r'开票日期[:：]\s*(\d{4})年(\d{1,2})月(\d{1,2})日?'
        match = re.search(invoice_date_pattern, self._text)
        if match:
            year, month, day = match.groups()
            return f"{year}-{month.zfill(2)}-{day.zfill(2)}"
        
        # 策略2：匹配其他日期格式
        date_patterns = [
            r'(\d{4})年(\d{1,2})月(\d{1,2})日',
            r'(\d{4})年(\d{1,2})月(\d{1,2})',
            r'(\d{4})[-/.](\d{1,2})[-/.](\d{1,2})',
        ]
        
        for pattern in date_patterns:
            matches = re.findall(pattern, self._text)
            for match in matches:
                if len(match) == 3:
                    year, month, day = match
                    if 1 <= int(month) <= 12 and 1 <= int(day) <= 31:
                        return f"{year}-{month.zfill(2)}-{day.zfill(2)}"
        
        # 策略3：返回文件修改日期
        import os
        import time
        mod_time = os.path.getmtime(self.pdf_path)
        return time.strftime('%Y-%m-%d', time.localtime(mod_time))
    
    def extract_invoice_type(self) -> str:
        """
        提取发票类型
        
        策略：
        1. 优先匹配"发票类型:"字段
        2. 匹配标题中的发票类型
        3. 通过关键词判断
        """
        type_keywords = {
            "专票": ["增值税专用发票", "电子专用发票", "专用发票"],
            "普票": ["增值税普通发票", "电子普通发票", "普通发票"],
        }
        
        # 策略1：匹配"发票类型:"字段
        invoice_type_pattern = r'发票类型[:：]\s*([^\n]+)'
        match = re.search(invoice_type_pattern, self._text)
        if match:
            invoice_type = match.group(1).strip()
            for standard_type, keywords in type_keywords.items():
                for keyword in keywords:
                    if keyword in invoice_type:
                        return standard_type
            return invoice_type
        
        # 策略2：匹配标题格式
        title_pattern = r'电子发票\s*[（(]([^)）]+)[)）]'
        match = re.search(title_pattern, self._text)
        if match:
            title_type = match.group(1).strip()
            for standard_type, keywords in type_keywords.items():
                for keyword in keywords:
                    if keyword in title_type:
                        return standard_type
        
        # 策略3：关键词匹配
        for standard_type, keywords in type_keywords.items():
            for keyword in keywords:
                if keyword in self._text:
                    return standard_type
        
        return "普票"
    
    def extract_product_type(self) -> str:
        """
        提取商品类型
        
        策略：
        1. 匹配"货物或应税劳务名称"字段
        2. 匹配"项目名称"字段
        3. 提取*包裹的内容
        """
        patterns = [
            r'货物或应税劳务.*?名\s*称[:：]\s*([^\n]+)',
            r'项目名称[:：]\s*([^\n]+)',
            r'商品名称[:：]\s*([^\n]+)',
            r'服务名称[:：]\s*([^\n]+)',
        ]
        
        for pattern in patterns:
            match = re.search(pattern, self._text)
            if match:
                product = match.group(1).strip()
                product = product.replace('*', '').strip()
                if product:
                    return product[:20]
        
        # 提取*包裹的内容
        star_pattern = r'\*([^*]+)\*'
        matches = re.findall(star_pattern, self._text)
        if matches:
            product = matches[0].strip()
            if product and len(product) > 1:
                return product[:20]
        
        return "商品"
    
    def extract_buyer_name(self) -> str:
        """
        提取购买方名称
        
        策略：
        1. 匹配"购买方信息"区域内的"名称:"
        2. 查找第一个包含公司关键词的"名称:"
        3. 查找第一个公司名称
        """
        # 策略1：匹配"购买方信息"区域
        buyer_pattern = r'购[买\n]*方[\n\s]*信[\n\s]*息[\n\s]*.*?名[\n\s]*称[：:]\s*([\u4e00-\u9fa5a-zA-Z0-9（）()]+)'
        match = re.search(buyer_pattern, self._text, re.DOTALL)
        if match:
            buyer = match.group(1).strip().replace('\n', '').replace(' ', '')
            if len(buyer) > 4:
                return buyer[:30]
        
        # 策略2：查找第一个包含公司关键词的"名称:"
        name_pattern = r'名[\n\s]*称[：:]\s*([\u4e00-\u9fa5a-zA-Z0-9（）()]+)'
        matches = re.findall(name_pattern, self._text)
        for buyer in matches:
            buyer = buyer.strip().replace('\n', '').replace(' ', '')
            if len(buyer) > 4 and any(keyword in buyer for keyword in ['公司', '企业', '股份', '有限', '集团', '厂', '店', '中心', '工作室']):
                return buyer[:30]
        
        # 策略3：查找第一个公司名称
        company_pattern = r'([\u4e00-\u9fa5a-zA-Z0-9（）()]*(?:公司|企业|股份|有限|集团|厂|店|中心|工作室)[\u4e00-\u9fa5a-zA-Z0-9（）()]*)'
        matches = re.findall(company_pattern, self._text)
        for buyer in matches:
            buyer = buyer.strip().replace('\n', '').replace(' ', '')
            if len(buyer) > 4:
                return buyer[:30]
        
        return "购买方"
    
    def extract_seller_name(self) -> str:
        """
        提取销售方名称
        
        策略：
        1. 匹配"销售方信息"区域内的"名称:"
        2. 查找第二个"名称:"（第一个是购买方）
        3. 查找最后一个公司名称
        """
        # 策略1：匹配"销售方信息"区域
        seller_pattern = r'销[售\n]*方[\n\s]*信[\n\s]*息[\n\s]*.*?名[\n\s]*称[：:]\s*([\u4e00-\u9fa5a-zA-Z0-9（）()]+)'
        match = re.search(seller_pattern, self._text, re.DOTALL)
        if match:
            seller = match.group(1).strip().replace('\n', '').replace(' ', '')
            if len(seller) > 4:
                return seller[:30]
        
        # 策略2：查找第二个"名称:"
        name_pattern = r'名[\n\s]*称[：:]\s*([\u4e00-\u9fa5a-zA-Z0-9（）()]+)'
        matches = re.findall(name_pattern, self._text)
        if len(matches) >= 2:
            seller = matches[1].strip().replace('\n', '').replace(' ', '')
            if len(seller) > 4 and any(keyword in seller for keyword in ['公司', '企业', '股份', '有限', '集团', '厂', '店', '中心', '工作室']):
                return seller[:30]
        
        # 策略3：查找最后一个公司名称
        company_pattern = r'([\u4e00-\u9fa5a-zA-Z0-9（）()]*(?:公司|企业|股份|有限|集团|厂|店|中心|工作室)[\u4e00-\u9fa5a-zA-Z0-9（）()]*)'
        matches = re.findall(company_pattern, self._text)
        if matches:
            seller = matches[-1].strip().replace('\n', '').replace(' ', '')
            if len(seller) > 4:
                return seller[:30]
        
        return "销售方"
```

#### 3.2.4 火车票提取器 (train_ticket.py)

```python
import re
from .base import InvoiceExtractor


class TrainTicketExtractor(InvoiceExtractor):
    """
    火车票/铁路电子客票提取器
    
    火车票的特殊性：
    - 金额通常是票价
    - 没有明确的购买方/销售方
    - 日期是乘车日期
    """
    
    INVOICE_TYPE_KEYWORDS = ['火车票', '铁路电子客票', '列车票']
    
    def extract_amount(self) -> float:
        """提取票价"""
        patterns = [
            r'票价[:：]\s*(\d+(?:\.\d+)?)',
            r'金额[:：]\s*(\d+(?:\.\d+)?)',
            r'¥\s*(\d+(?:\.\d+)?)',
        ]
        
        for pattern in patterns:
            match = re.search(pattern, self._text)
            if match:
                try:
                    return float(match.group(1))
                except ValueError:
                    pass
        
        return 0.0
    
    def extract_invoice_date(self) -> str:
        """提取日期（乘车日期或开票日期）"""
        # 优先匹配乘车日期
        patterns = [
            r'乘车日期[:：]\s*(\d{4})[-年](\d{1,2})[-月](\d{1,2})',
            r'日期[:：]\s*(\d{4})[-年](\d{1,2})[-月](\d{1,2})',
            r'(\d{4})[-年](\d{1,2})[-月](\d{1,2})',
        ]
        
        for pattern in patterns:
            match = re.search(pattern, self._text)
            if match:
                year, month, day = match.groups()
                return f"{year}-{month.zfill(2)}-{day.zfill(2)}"
        
        # 返回文件修改日期
        import os
        import time
        mod_time = os.path.getmtime(self.pdf_path)
        return time.strftime('%Y-%m-%d', time.localtime(mod_time))
    
    def extract_invoice_type(self) -> str:
        """返回票种类型"""
        return "火车票"
    
    def extract_product_type(self) -> str:
        """火车票没有商品类型，返回空"""
        return ""
    
    def extract_buyer_name(self) -> str:
        """火车票通常没有明确的购买方名称，返回空"""
        # 尝试提取乘客姓名
        pattern = r'旅客[:：]\s*([^\n]+)'
        match = re.search(pattern, self._text)
        if match:
            return match.group(1).strip()[:30]
        return ""
    
    def extract_seller_name(self) -> str:
        """火车票销售方通常是铁路局，返回空或铁路局名称"""
        # 可以返回"中国铁路"或根据票面信息提取
```

## 七、总结

本方案通过**策略模式**将每种票种的字段提取逻辑完全隔离，实现：

1. ✅ **修改隔离**：修改A票种不会影响B票种

3. ✅ **易于扩展**：新增票种只需添加新类
4. ✅ **向后兼容**：保留原有接口，不影响调用方
5. ✅ **可测试性**：每个提取器可独立单元测试
