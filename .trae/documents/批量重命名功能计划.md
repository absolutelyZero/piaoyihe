# 批量重命名功能实施计划

## 项目概述
在现有的发票合并工具中新增批量重命名功能，允许用户根据发票字段（发票类型、商品类型、开票日期、买方名字、销方名字）自定义文件名规则，对文件列表中的PDF文件进行批量重命名。

## 需求分析

### 功能需求
1. **按钮位置**: 在"合并PDF"按钮前添加"重命名"按钮，两者之间用分割线隔开
2. **弹窗界面**: 点击"重命名"按钮弹出配置对话框，包含：
   - 标题：显示"请设置重命名【发票类型】文件的规则"
   - 文本框：用于输入文件名规则，支持占位符
   - 字段按钮：发票类型、商品类型、开票日期、买方名字、销方名字（点击可插入到文本框）
   - 保存按钮：保存当前规则到配置文件
   - 清空按钮：清空文本框内容
   - 执行按钮：按照规则执行批量重命名
   - 使用说明：显示规则使用说明

### 技术需求
1. 从PDF中提取更多字段信息（买方名字、销方名字、商品类型、发票类型）
2. 配置文件需要保存重命名规则
3. 支持占位符替换（如 `{开票日期}`、 `{买方名字}` 等）
4. 非法字符过滤（Windows文件名不允许的字符）

## 详细设计

### 1. PDF字段提取规则

```python
# 发票类型关键词映射
INVOICE_TYPE_KEYWORDS = {
    "普通发票": ["普通发票", "电子普通发票", "增值税普通发票"],
    "专用发票": ["专用发票", "电子专用发票", "增值税专用发票"],
    "机动车发票": ["机动车", "二手车"],
    "火车票": ["火车票", "铁路电子客票"],
    "飞机票": ["航空", "机票", "电子客票"],
}

# 字段提取正则模式
FIELD_PATTERNS = {
    "buyer": r'购买方.*?名\s*称[:：]\s*([^\n]+)',
    "seller": r'销售方.*?名\s*称[:：]\s*([^\n]+)',
    "product": r'货物或应税劳务.*?名\s*称[:：]\s*([^\n]+)',
}
```

### 2. 重命名规则格式

- 占位符格式：`{字段名}`
- 支持的字段：
  - `{发票类型}` - 发票类型
  - `{商品类型}` - 商品或服务类型
  - `{开票日期}` - 开票日期（YYYY-MM-DD）
  - `{买方名字}` - 购买方名称
  - `{销方名字}` - 销售方名称
  - `{金额}` - 发票金额

- 示例规则：
  - `{买方名字}-{开票日期}-{商品类型}`
  - `{销方名字}_{开票日期}_{金额}元`

### 3. 非法字符过滤

Windows文件名不允许的字符：`< > : " / \ | ? *`

替换策略：替换为下划线 `_` 或直接删除
