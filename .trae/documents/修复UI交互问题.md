# 修复计划：UI交互问题修复

## 问题列表

### 1. 拖拽后列表样式和内容错乱
**现状**：从截图可以看到，拖拽后第二行显示异常（蓝色背景，内容变成日期和大小）
**期望**：拖拽后列表样式保持正常，内容正确显示
**分析**：
- 问题出在 `dropEvent` 方法中，直接操作了 `self.files` 列表，但没有正确处理表格的排序状态
- 当表格处于排序状态时，视觉行顺序和数据顺序不一致
- 需要禁用排序后再进行拖拽操作，或者正确映射视觉行到数据索引

**修复方案**：
- 修改 `dropEvent` 方法，在拖拽前禁用排序
- 或者使用 `self.table.rowAt()` 获取正确的视觉行索引
- 确保拖拽后调用 `_update_table()` 正确刷新显示

### 2. 反馈按钮样式和弹窗内容
**现状**：
- 右上角反馈按钮样式不对（蓝色圆形）
- 点击后的弹窗内容与重构前不一致
**期望**：
- 反馈按钮恢复原来的样式（问号图标）
- 弹窗内容与原来保持一致

**修复方案**：
- 修改 `_create_top_widget()` 中的反馈按钮样式
- 检查 `FeedbackDialog` 类，恢复原来的内容布局

### 3. 双击打开改为右键菜单
**现状**：左键双击打开文件
**期望**：右键点击显示菜单，包含"打开文件"选项

**修复方案**：
- 在 `FileListPanel` 中移除双击事件
- 添加 `contextMenuEvent` 或 `customContextMenuRequested` 信号
- 创建右键菜单，包含"打开文件"、"删除"等选项

### 4. 布局选择样式和文字
**现状**：布局选择显示为 "1×2"、"1×3"、"2×4"、"2×2"
**期望**：
- 增加单选框样式
- 文字改为："竖向1x2"、"竖向1x3"、"横向2x2"、"横向2x4"

**修复方案**：
- 修改 `_create_options_widget()` 中的单选按钮文字
- 确保单选按钮样式正确显示
