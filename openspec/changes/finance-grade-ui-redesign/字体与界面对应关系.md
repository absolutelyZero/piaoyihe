# 票易合 v2 · 字体与界面对应关系（字体对齐基线）

> 权威来源：设计稿 `req/ui/00`–`04`、设计稿 `.op` 源文件（`fontFamily` 节点）。
> 实现唯一来源：`code/ui/tokens.py`。本文件是字体映射与冲突清单的说明文档，不参与运行时。

---

## 1. 设计稿字体清单

| 用途 | 字体族 | 随程序打包字体 | 许可 |
| --- | --- | --- | --- |
| 中文 | Noto Sans SC（可变字体） | `code/res/fonts/NotoSansSC-VF.ttf` | SIL OFL 1.1 |
| 数字 | Inter（可变字体）+ OpenType `tnum` | `code/res/fonts/Inter-VF.ttf` | SIL OFL 1.1 |

- 设计稿 `.op` 源文件中，所有数字节点的 `fontFamily` 均为 **Inter**；中文节点为 **Noto Sans SC**。
- `req/ui/00` 说明页「等宽数字样例」上出现的 `Geist Mono` 是该行标签的示意文字，**不是设计稿字体**。
  Geist Mono / JetBrains Mono / Consolas 在目标机不存在会静默回退 Arial（比例数字、字形不符），
  并让 Qt 额外做一次字体别名扫描拖慢启动，已全部从实现字体栈移除。
- 数字用 `tnum`（tabular numerals）得到等宽数字，再右对齐；**不切换到等宽字体族**。

### 字体栈（`tokens.py`）

```text
FONT_CN_STACK   = "Noto Sans SC","Source Han Sans SC","Source Han Sans CN","Microsoft YaHei","PingFang SC","SimHei","DengXian",sans-serif
FONT_MONO_STACK = "Inter","Noto Sans SC",monospace
```

`FONT_MONO_STACK` 末尾含 `Noto Sans SC`，使**中文混排文本**中的中文能回退到设计稿中文字体，数字仍走 Inter。

### 启动顺序（不可变）

```text
QApplication 创建
  → apply_application_style()
      → register_bundled_fonts()      # 注册 Inter-VF / NotoSansSC-VF
      → app.setStyleSheet(build_stylesheet())
      → app.setFont(Noto Sans SC, 13px, Weight.Normal 400)
  → 构建窗口 / 对话框
      → clear_inline_styles(root)
      → apply_numeric_text_fonts(root)   # 数字位 setFont(Inter + tnum)
```

顺序错了 QSS 里的字体名会回退到系统里另一种字形。应用级默认字体用 `setPixelSize(13)`（px），
**不写 `QFont(family, 9)`**（=12px，偏小发虚）。深色/浅色主题只换色值，字体族、字号、字重完全相同。

## 2. 字重 / 字号档位常量（`tokens.py`）

设计稿 `req/ui/00`「05 / 字体与数字」标注：`Regular 13 / Medium 14 / SemiBold 16 / Bold 20`，
行高 22、字距 0。Qt/QSS 使用 100–900 数值字重，映射集中定义在 `FONT_WEIGHT` / `FONT_SIZE`：

| 设计稿命名 | 数值字重 | 常量键 | 界面用途 |
| --- | --- | --- | --- |
| Regular | 400 | `FONT_WEIGHT["regular"]` | 正文、表头常规、chip |
| Medium | 500 | `FONT_WEIGHT["medium"]` | 次级强调 |
| SemiBold | 600 | `FONT_WEIGHT["semibold"]` | 选中态、强调标签、执行按钮 |
| Bold | 700 | `FONT_WEIGHT["bold"]` | 标题、主按钮、金额合计 |

| 字号键 | px | 界面用途 |
| --- | --- | --- |
| `micro` | 10 | 进度条百分比 |
| `caption` | 11 | 次级/弱化文字、表头、状态栏、版本号 |
| `body` | 12 | 参数值、表格数据、芯片 |
| `base` | 13 | 正文基线（`FONT_BODY_PIXEL_SIZE`） |
| `subhead` | 14 | 卡片标题、主按钮 |
| `title` | 15 | 品牌名、合计金额 |
| `heading` | 16 | 台账标题、弹窗小节标题 |
| `dialog` | 18 | 弹窗主标题 |

> **Bold 20px（`DESIGN_DISPLAY_SIZE`）：【设计稿展示用，界面不消费】**
> 仅用于 `req/ui/00` 说明页大标题「票易合 · 财务级 UI 重构设计说明」。
> 界面中没有对应控件，因此**未加入 `FONT_SIZE`、未生成任何 20px QSS 规则**，请勿据此新增。

QSS 中所有 `font-size` / `font-weight` 均引用 `{S[...]}` / `{W[...]}` 常量，源码中无魔法数字。

| `titleLabel` | 16 / 700 | 旧版大标题兼容位 |

| `brandTitle` | 15 / 700 | 标题栏「票易合」 |

### 数字位（`Inter + tnum`，由 `numeric_font()` / `apply_numeric_text_fonts()` 通过 `setFont()` 提供）

| 位置 | 字号 | 实现 |
| --- | --- | --- |
| 台账 9 列中的数值列 | 发票号码 11，其余 12 | `file_list.py::_apply_financial_cell_style()` → `numeric_font()` |
| 合计金额（标题栏 + 页脚） | 15 / 700 | `shell.py` → `numeric_font(15, bold)` |
| 缩放比例 `80%` | 12 | `shell.py` → `numeric_font(12)` |
| 标题栏版本号 `v0.1.15` | 11 | `shell.py` → `numeric_font(11)` |
| 状态栏票据数、页码、每页张数、记录数、重复计数 chip、参数数值、参数标签 | 11 / 12 | `apply_numeric_text_fonts()` → `NUMERIC_TEXT_SIZES` |
| 输出路径框、行/列/页边距/裁切线 SpinBox | 12 | `apply_numeric_text_fonts()` → `NUMERIC_INPUT_OBJECTS` |
| 重命名示例结果、更新弹窗版本号 | 11 / 12 | 各弹窗 → `numeric_font()` |

右对齐列：金额(3) / 税额(4) / 大小(8)；金额列主色；路径列弱化灰。
`_update_table()` 每次重建行后都会重新调用 `_apply_financial_cell_style()`，避免「只有最后一行生效」。

### 必须保持中文栈的混排内容

- `ruleInput`（重命名规则含中文占位符）、`fieldChip` / `fieldChipExtra`（中文字段名）、
  帮助说明正文、二维码提示、按钮文字、中文下拉（`modeCombo` / `orderCombo`）。
- 这些控件**不得**使用数字字体，否则中文会被回退到非设计稿字体。

### 三层数字字体策略（Qt 技术约束下的实现）

1. **表格数值列**：`QTableWidgetItem.setFont(numeric_font(px))` — item 的 FontRole 优先于 QSS，
   `tnum` 生效，小数点按列对齐。
2. **纯数字/金额标签与输入控件**：`QWidget.setFont(numeric_font(px))`，且对应 QSS 规则
   **不声明 `font-family`**（否则 Qt QSS 会覆盖 `setFont()`，导致 `tnum` 丢失）。
3. **中文 + 数字混排的次级文本**：`apply_numeric_text_fonts()` 用带中文回退链的
   `numeric_font()` 统一设置；中文经 `setFamilies` 回退到 Noto Sans SC，数字走 Inter + tnum。

> Qt QSS **不支持** OpenType `font-feature-settings` / `tnum`，也不支持按字符切换字体。
> 因此凡需 `tnum` 的控件一律走 `setFont()`；QSS 只负责字号、颜色与几何，不声明字体族。

## 4. QSS 与 `setFont()` 冲突清单（本次已全部消除）

| # | 冲突点 | 原状态 | 处置 |
| --- | --- | --- | --- |
| 1 | 表头字重 | `QHeaderView::section { font-weight: 500 }` 与 `file_list.py::_apply_header_colors()` 的 `setBold()` 同时指定 | QSS 移除表头 `font-size`/`font-weight`；统一由 `tokens.header_font(bold)` 单一来源生成（11px / Noto Sans SC / Regular，仅金额列 Bold + 主色） |
| 2 | 通用 `QLabel` 字体 | `QLabel { font-family; font-size: 13px }` 会覆盖所有数字位的 `setFont()`，`tnum` 失效 | 通用 `QLabel`、`QMainWindow`/`QDialog` 规则不再声明 `font-*`；默认字体由 `app.setFont()` 唯一提供，各 `objectName` 规则显式给字号 |
| 3 | 通用表单字体 | `QLineEdit, QComboBox, QSpinBox` 的 `font-family` 覆盖数字输入框的 `setFont()` | 通用表单规则移除 `font-family`；数字输入位纳入 `NUMERIC_INPUT_OBJECTS` 由 `numeric_font()` 覆盖；`ruleInput` 显式保留中文栈 |
| 4 | 纯数字标签 | `versionLabel` / `monoLabel` / `ledgerTotalLabel` / `exampleValue` 规则内声明 `font-family`/`font-size`/`font-weight`，与 `setFont()` 重复 | 这些规则只保留颜色与几何，字体全部由 `numeric_font()` 单一来源提供 |
| 5 | 混排数字文本 | 状态栏/页码/chip 走中文栈比例数字，与设计稿 Inter 字形不符 | 加入 `NUMERIC_TEXT_OBJECTS`，由 `apply_numeric_text_fonts()` 集中设置 Inter + tnum |
| 6 | 逐控件内联样式 | `main_frame.py` 帮助正文、二维码标签、分隔线等 9 处 `setStyleSheet` 写 `font-size` | 全部改为 `setObjectName()` + QSS 规则（`helpText` / `qrcodeHint` / `qrcodePlaceholder` / `hSeparator`）；旧版遗留方法中的同类内联声明与注释一并清理 |

**非冲突的分层覆盖（保留）**：`QTableWidget` 的 12px 中文栈是单元格默认值（供文件名/路径中文列使用），
6 个数值列与表头由 `setFont()` 覆盖 —— item 的 FontRole 优先于控件 QSS，属设计意图，实测 11px/12px 均生效。

## 5. 验收

- `python -m unittest tests.test_ui_tokens tests.test_font_alignment`：常量、映射、QSS 无魔法数字、
  表头单一来源、`tnum`、无内联字体样式。
- `tests.test_ui_shell` / `tests.test_ui_merge_behavior` 及既有业务回归须全绿。
- 离屏截图：`QT_QPA_PLATFORM=offscreen` + `QT_QPA_FONTDIR=C:/Windows/Fonts`，
  抓主工作台 / 重命名弹窗 / 深色三张，与 `req/ui/01`、`02`、`04` 逐块比对字形、字号、字重。
  不设 `FONTDIR` 时离屏 Qt 加载不到字体导致中文方框，属环境限制，非代码问题。
- 不得出现：中文方框、数字比例字体导致小数点不对齐、QSS 与内联样式互相覆盖。
