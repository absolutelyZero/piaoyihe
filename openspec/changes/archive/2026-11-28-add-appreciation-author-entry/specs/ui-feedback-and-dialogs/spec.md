# Spec Delta

## ADDED Requirements

### Requirement: 赞赏作者弹窗展示引导与收款码

赞赏作者弹窗 SHALL 沿用「使用帮助」「检查更新」「变量说明」共用的统一标题栏、内容区与页脚结构，在内容区展示赞赏引导文案，并在引导下方同时展示微信支付与支付宝两张收款码，每张 SHALL 带有可辨识的支付方式标注。

#### Scenario: 弹窗内容与结构
- **WHEN** 用户打开赞赏作者弹窗
- **THEN** 弹窗包含标题栏（标题 + 关闭）、内容区（赞赏引导文案）与页脚操作区，内容区并排展示微信支付与支付宝收款码并分别标注支付方式

#### Scenario: 收款码图片不可用
- **WHEN** 任一收款码图片缺失、损坏或无法加载
- **THEN** 弹窗仍正常显示引导文案与另一张可用收款码，缺失位置显示明确占位提示，不导致弹窗或主窗口崩溃
